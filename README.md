# 🎙️ منصة راديو كينج الذكي - Smart Radio King

منصة بث إذاعي متكاملة ومتقدمة تعتمد على بيئة تشغيل **Node.js** و **JavaScript** النقي. تتيح للمذيعين والفنانين بث الصوت الحي مباشرة من الميكروفون وتحديث أغلفة الألبومات والدردشة والتفاعل مع المستمعين لحظياً وبأقل زمن تأخير ممكن (Low Latency).

---

## ✨ المميزات الرئيسية (Features)

* **بث ميكروفون لحظي المتطور**: تقطيع حزم الصوت وإرسالها كل 400 ملي ثانية بصيغة `WebM/Opus` خفيفة الوزن لتوفير استهلاك البيانات.
* **لوحة تحكم الفنان والتحكم بغلاف الهواء**: إمكانية تغيير الأغنية الحالية وصورة الألبوم وتحديث بيانات الـ RDS فوراً لجميع المستمعين.
* **مؤشر صوت بصري تفاعلي (VU Meter & Visualizer)**: عداد صوت متحرك للمذيع ومؤشر ترددات موجي للمستمعين يعمل بمحرك `Web Audio API`.
* **تفاعل حي ومرح**: نظام إيموجي متطاير (Floating Emojis) للحفلات والتفاعل اللحظي مع شات مؤمّن وسريع.
* **تصميم مرن ومتجاوب**: واجهة مستخدم ليلية ونهارية جذابة ومخصصة لسهولة اللمس والتحكم عبر الهواتف الذكية.

---

## 🛠️ التثبيت والتشغيل المحلي (Local Setup)

لتشغيل المشروع على حاسوبك الشخصي، اتبع الخطوات التالية:

1. **تحميل المشروع أو عمل Clone**:
```bash
git clone https://github.com
cd Smart-Radio
```

2. **تثبيت الحزم والاعتماديات**:
```bash
npm install
```

3. **بدء تشغيل السيرفر**:
```bash
npm start
```
أو للتشغيل في بيئة التطوير مع التحديث التلقائي للملفات:
```bash
npm run dev
```

4. **تصفح الواجهات**:
* واجهة المستمع: `http://localhost:3000/listener.html`
* لوحة المذيع: `http://localhost:3000/index.html`
* لوحة تحكم الفنان: `http://localhost:3000/artist.html`

---

## 🌐 روابط التقنيات المستخدمة (Tech Stack)
* **Backend**: Node.js, Express, Multer
* **Frontend**: Vanilla JavaScript, Canvas API, Web Audio API
